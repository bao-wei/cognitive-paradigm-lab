# Stroop 色词干扰

## 学习目标

亲手观察自动化阅读过程如何干扰当前的颜色判断任务，理解自变量、因变量和 Stroop 干扰效应。

## 实验原理

我们已经非常熟练地阅读文字，文字含义往往会自动进入加工。当颜色词的含义与字体颜色不一致时，文字含义会与当前需要作出的颜色反应竞争，通常造成更慢的反应或更多错误。

## 你的任务

屏幕会呈现“红、绿、蓝、黄”等颜色词。请忽略文字写的是什么，只判断文字本身的颜色。电脑可按对应数字键，手机可点击实验画面下方的对应按钮。

- `1`：红色
- `2`：绿色
- `3`：蓝色
- `4`：黄色

实验包含简短练习和 20 个正式试次。请兼顾速度与准确性。

## 记录指标

- 正确率：正式试次中正确反应的比例。
- 平均反应时：仅统计正确反应，从刺激出现到按键的时间。
- 干扰效应：不一致条件平均反应时减去一致条件平均反应时。

## 如何理解结果

正的干扰效应表示这一次体验中，不一致条件比一致条件更慢。单次短实验容易受到练习、疲劳、设备和随机波动影响，不能用于评价个人能力。
