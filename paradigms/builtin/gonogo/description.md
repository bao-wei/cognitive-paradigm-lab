# Go / No-Go 任务

## 学习目标

观察高频反应倾向形成后，个体如何在少数关键信号出现时停止已经准备好的动作。

## 实验原理

频繁出现的 Go 刺激会建立持续按键倾向。较少出现的 No-Go 刺激要求参与者抑制这一反应，因此可用于演示反应抑制。

## 你的任务

- 看到绿色圆形：尽快按下空格键。
- 看到红色圆形：不要按任何键，等待下一个刺激。

实验包含简短练习和 28 个正式试次。请兼顾速度与准确性。

## 记录指标

- 正确率：Go 和 No-Go 正确试次占全部正式试次的比例。
- 平均反应时：正确 Go 试次的平均反应时间。
- 抑制成功率：No-Go 试次中成功不按键的比例。

## 如何理解结果

抑制成功率反映这一次短任务中成功停止反应的比例。它受到按键习惯、注意状态和试次数量影响，不能作为个人冲动控制能力的诊断。
