# McGurk 材料来源

真人语音视频来自 Beauchamp Lab 公开发布的实验材料，Basu Mallick、Magnotti 与 Beauchamp（2015），DOI 10.3758/s13423-015-0817-4。

原始发布页及版权放弃声明：https://openwetware.org/wiki/Beauchamp:Stimuli

原页面声明在法律允许范围内放弃材料版权及相关权利，并链接 CC0：https://creativecommons.org/publicdomain/zero/1.0/

`mcgurk-ba-N.mp4` 对应原始 `All_ba_stimuli.zip/all_ba_stimuli/4.N.mp4`；`mcgurk-fusion-N.mp4` 对应原始 `Experiment2_McGurkStimuli.zip/2.N.mp4`，N 为 1–8。文件内容未修改。具体压缩包地址和英文来源说明见 MCGURK-SOURCES.txt。
