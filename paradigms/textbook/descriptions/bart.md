# 学习目标
体验在不确定条件下权衡收益与爆炸风险。

# 实验操作
20 个气球，每次充气获得 1 个模拟积分。每个气球的爆炸阈值独立从 1—32 次中等概率抽取，达到阈值即爆炸；这一缩短参数用于课堂体验，不是临床常模。可随时保存本轮收益。

# 指标与解释
调整后平均充气次数只统计未爆炸气球；另记录爆炸比例、总收益、每轮充气次数和选择时间。爆炸概率在生存至后一次充气时随剩余阈值数减少而升高。

# 注意事项
没有真实奖金，20 轮任务不能用于判断人格、冲动性或现实冒险倾向。全部爆炸时调整后均值显示数据不足。
