# 学习目标
观察子目标提示与搜索、回退之间的关系。

# 实验操作
系统随机分配提示或无提示条件，完成 20 轮三盘河内塔。每轮 A 柱按大、中、小顺序放盘，目标是全部移至 C 柱；只允许移动顶盘，大盘不能压小盘。每轮最长 120 秒，可主动结束并保留未完成记录。最少合法移动是 7 步。

# 指标与解释
记录每次选择、合法移动、违例、立即逆向回退、完成时间和是否完成。不能只依据速度评价策略。相同问题的重复练习具有明显学习效应，随机提示组和无提示组应结合首轮表现及既有经验讨论。

# 注意事项
这是操作过程演示，不是智力测试，不会显示未实际收集的组间差异。
