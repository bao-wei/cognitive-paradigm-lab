# 学习目标
体验语义关联如何影响记忆和再认时的确信度。

# 实验操作
学习 4 组共 20 个中文词，每词 1500 毫秒，随后自由回忆和 20 次再认，逐题报告确信度。两组词与对应主题高度关联，另外两组关联较弱；词语是教学材料，未使用标准化联想强度常模。系统在即时测验和 30 秒算术填充后的延迟测验之间随机分组。

# 指标与解释
旧词命中率、新词虚报率、关键诱饵虚报率、自由回忆成绩及确信度校准。结果页才揭示未学习的关键诱饵。不预填虚假记忆效应，不把一次练习解释为个人能力。

# 注意事项
高低关联材料未经过中文词频和联想强度常模匹配，课堂可讨论这一限制。延迟只用于体验操作，不等同长期记忆研究。

# 来源与参考
Deese（1959）；Roediger 与 McDermott（1995）；教材 6-4 要求。
