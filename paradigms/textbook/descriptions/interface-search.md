# 学习目标与原理
体验功能分组、留白和标题层级对目标搜索的影响。

# 任务流程
两种界面各 10 个正式任务，共 20 次，区组顺序随机。两种界面均包含相同的 18 个功能；高密度界面无功能标题且功能随机排列，分组界面按文件与数据、账户与安全、工作与协作组织。任务包含导出数据、账户安全和保存状态等，错误点击后继续寻找目标。每区组结束报告 1–7 分主观难度。

# 指标与含义
记录目标发现 RT、首次操作正确率、错误点击数、点击顺序与主观难度。首次注视目标区域时间和无关区域注视次数需要眼动设备，本网页不测量，CSV 中明确记为未采集，不使用鼠标行为替代眼动。

# 注意事项与来源
两种界面的屏幕大小与操作设备应尽量一致；重复相同功能可能产生练习效应。本实验是信息组织与视觉搜索的人机交互教学演示，不评价个人能力。
